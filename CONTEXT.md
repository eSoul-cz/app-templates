## Commit convention

Commit messages are English and describe what the commit does (required). This repository uses the recommended Gitmoji format below; a developer MAY use their own commit standard, and the agents of a developer who has none use this one. Use the `gitmoji-commit` skill for agent-authored commits in this format.

```text
:sparkles: [checkout] Add delivery selection

optional explanatory details
```

In the Gitmoji format use one shortcode per commit and split commits by intention. Context is optional (in this repository the layer or area: `[builder]`, `[common]`, `[laravel/base]`). The message is imperative and starts with an uppercase letter. Keep the complete subject line at 72 characters or fewer when practical.
